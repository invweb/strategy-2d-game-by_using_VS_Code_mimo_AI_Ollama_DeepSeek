2026-07-26 — Bug Fixes and Improvements
=========================================

BUG FIXES
---------

1. ActionQueue Thread Safety (common/logic/ActionQueue.kt)
   - Added @Synchronized annotations to enqueue(), processAll(), and clear()
   - Problem: pendingActions was a shared mutable list accessed from multiple threads
     (AI background thread + GL thread). Without synchronization, race conditions could
     cause ConcurrentModificationException or lost actions.

2. UnitStack.split() Dead Code (common/model/Unit.kt)
   - Removed duplicate code block — both branches of if (half) did the same thing
   - Problem: The half parameter was meaningless; both paths executed identical logic.

3. Camera Panning Bug (desktop/GameScreen.kt, desktop/GameInput.kt)
   - Fixed render() method where camera.translate(Gdx.input.x - Gdx.input.x, ...) always
     computed 0
   - Added cancelPanning() method to GameInput
   - Problem: Panning was silently broken — camera never moved during right-click drag
     in the render loop.

4. Unsafe player!! (desktop/GameScreen.kt)
   - Replaced player!! with safe val player = state.currentPlayer() ?: return
   - Problem: Could crash with NPE if game state was inconsistent.

# Plan: Java 17 Toolchain Configuration

## Summary
Configure Gradle to automatically download and use Java 17, removing the need for manual JAVA_HOME setup.

## Changes

### 1. Update gradle.properties
- Add `org.gradle.java.installations.auto-download=true` to enable automatic JDK download

### 2. Update desktop/build.gradle.kts
- Replace hardcoded jpackage path with dynamic: `System.getProperty("java.home") + "/bin/jpackage"`

### 3. Update README.md
- Add Prerequisites section with Java 17 installation instructions for macOS/Linux/Windows
- Remove manual JAVA_HOME export from Running section

### 4. Verify Setup
- Run `./gradlew desktop:build` to test compilation
- Run `./gradlew desktop:installDist` to test packaging

## Expected Result
Project builds without manual Java configuration.

# Strategy — Пошаговая 2D-стратегия

## Описание

Прототип пошаговой 2D-стратегии, вдохновлённый игрой "Imperialism 2", построенный на **libGDX + Kotlin + Kotlin Multiplatform**. Работает на macOS в режиме десктопа. Поддерживает **3 языка**: английский, русский, немецкий.

## Технологии

- **Kotlin 2.0.21** + Kotlin Multiplatform
- **libGDX 1.12.1** — рендеринг, ввод, UI, шрифты FreeType
- **kotlinx.serialization** — JSON сериализация
- **Ollama** — локальный AI-сервер для противника
- **LM Studio** — альтернативный локальный AI-сервер (совместимый с OpenAI API)
- **DeepSeek R1 (7B)** — модель рассуждений для принятия решений ИИ

## Возможности

- **Гексагональная сетка** с типами местности: Равнина, Лес, Холмы, Горы, Вода
- **Типы юнитов**: Пехота, Кавалерия, Осада — визуализируются на карте иконками
- **Постройки**: Ферма, Лесопилка, Казарма, Шахта, Стена — каждая даёт бонусы
- **Система сохранений**: Именованные сохранения с диалоговым интерфейсом, удаление с подтверждением
- **Выделение областью**: Клик-перетаскивание для выбора нескольких регионов
- **Локализация**: Английский, Русский, Немецкий — переключается в настройках
- **ИИ-противник**: Использует Ollama (DeepSeek R1) с автоматическим откатом на правила
- **Пошаговый бой**: Атака, оборона, вербовка юнитов, развитие территорий
- **Дипломатия**: Союз, торговые пути с противником
- **Древо технологий**: Земледелие, Обработка железа, Каменное дело, Укрепления, Верховая езда, Осадное дело
- **Асинхронный ИИ**: Ходы ИИ выполняются в фоновом потоке — нет заморозки UI

## ИИ

Игра поддерживает **3 бэкенда ИИ** — выберите в **НАСТРОЙКАХ**:

### None (Встроенный)
ИИ на основе правил, внешние зависимости не требуются. Работает сразу.

### Ollama
Локальный AI-сервер с моделью deepseek-r1:7b.

**Настройка:**
1. Установите Ollama: `curl -fsSL https://ollama.ai/install.sh | sh`
2. Скачайте модель: `ollama pull deepseek-r1:7b`
3. Запустите Ollama: `ollama serve`

### LM Studio
Альтернативный локальный AI-сервер с API, совместимым с OpenAI.

**Настройка:**
1. Скачайте и установите [LM Studio](https://lmstudio.ai)
2. Загрузите модель (например, DeepSeek, Llama, Mistral)
3. Запустите локальный сервер (по умолчанию: `http://localhost:1234`)
4. Укажите URL и название модели в **НАСТРОЙКАХ**

### Как это работает

Когда вы нажимаете **КОНЕЦ ХОДА**:
1. Ваше ожидающее действие (стройка/вербовка/атака/перемещение) применяется к состоянию игры
2. Ход переключается на ИИ-игрока
3. `TurnManager.startTurn()` применяет доход, содержание, туман войны и случайные события для ИИ
4. `OllamaAI.decide()` вызывается в **фоновом потоке** (неблокирующий):
   - Проверяет `AISettings.backend` для определения движка ИИ
   - Формирует промпт с ресурсами ИИ, территориями, позициями врага, статусом дипломатии
   - **Ollama**: отправляет HTTP POST на `{url}/api/generate`
   - **LM Studio**: отправляет HTTP POST на `{url}/v1/chat/completions` (совместимый с OpenAI формат)
   - Модель анализирует ситуацию и возвращает одно действие (например, `BUILD_FARM:3`, `RECRUIT:7`)
5. Действие ИИ передаётся обратно в GL-поток через `Gdx.app.postRunnable`
6. `applyAIAction()` выполняет действие, затем `TurnManager.endTurn()` переключает обратно на игрока
7. Если ответ ИИ занимает слишком много времени или сервер недоступен, **встроенный ИИ** работает сразу (на основе правил, без HTTP)

### Встроенный ИИ (без сервера)

**Игра полностью работает без Ollama или LM Studio.** Если выбранный бэкенд недоступен, ИИ использует стратегию на основе правил:

1. Строит Казарму если рядом враг и хватает ресурсов
2. Строит Стены если есть Казарма и рядом враг
3. Строит Ферму на пустых территориях (если хватает ресурсов)
4. Строит Шахту на горах (если хватает ресурсов)
5. Вербует войска если есть Казарма (если хватает ресурсов)
6. Развивает регионы если есть Золото (если хватает ресурсов)
7. Предлагает торговлю еслинейтрален и богат
